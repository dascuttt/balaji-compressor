## ⚡ हे कसे चालवायचे (How to Run Locally)

1. **थेट ब्राउझरमध्ये उघडा:**
   - कोणत्याही इंस्टॉलेशनशिवाय थेट `index.html` फाईलवर डबल-क्लिक करा.

2. **किंवा लोकल सर्व्हरवर चालवा:**
   ```powershell
   python -m http.server 3000
   ```
   ब्राउझरमध्ये उघडा: `http://localhost:3000`
